# Backuper

![Backuper](app_icon.png)

**Надёжное резервное копирование сетевой папки на локальный компьютер.**

Backuper решает простую, но важную задачу: файлы на сервере периодически пропадают —
программа автоматически хранит их копию у вас на ПК, следит за изменениями,
сохраняет предыдущие версии и позволяет вернуть любой файл обратно.

---

## ✨ Возможности

- 🔄 **Автоматическое копирование** каждые 2 часа и при входе в Windows.
- ⚡ **Мгновенная реакция** на новые/изменённые файлы — проверка папки каждые 20 секунд.
- 🛡 **Никогда не удаляет** файлы из копии, даже если они исчезли с сервера.
- 📜 **История версий**: `+ файл время` (добавлен/изменён) и `− файл время` (удалён).
- ↩️ **Восстановление** версии в копию или прямо на сервер (с подтверждением).
- 🔔 **Уведомления** в трее о результате копирования.
- 🗂 **Автоочистка** логов (7 дней) и версий (30 дней) по воскресеньям.
- 🖥 **Графическая панель** с русским интерфейсом, сворачиванием в трей и стильными кнопками.
- 📦 **Графический установщик** с обращением к GitHub за новой версией.

## 🚀 Установка

1. Скачайте **один файл `BackuperInstaller.exe`** из [последнего релиза](../../releases/latest).
2. Запустите его (понадобятся права администратора). Установщик **сам скачает все файлы
   программы с GitHub** — никакой архив скачивать не нужно.
3. В мастере укажите:
   - папку-источник на сервере (например `\\SERVER\transfer\карпов`);
   - папку установки (по умолчанию `C:\Program Files (x86)\Backuper`);
   - нужен ли ярлык на рабочем столе.
4. Нажмите **«УСТАНОВИТЬ»** — программа создаст задачи в Планировщике и запустит слежение.

Альтернатива: скопируйте всю папку с программой и запустите `Установить.cmd`.

---

## 🔄 Обновление

- В панели: **Настройки → «Проверить обновления»**.
- Программа обращается к GitHub API, сравнивает версию из `version.json` с последним релизом.
- При наличии новой версии скачивается ZIP-архив из релиза; ваши `settings.json`,
  `Files`, `Logs`, `Versions` и иконка при обновлении **сохраняются**.

Чтобы выпустить обновление: создайте Release с тегом `v1.1.0` и приложите ZIP
с файлами программы.

## 📁 Структура

| Файл | Назначение |
|---|---|
| `BackuperGUI.ps1` | Графическая панель |
| `Backup.ps1` | Копирование по расписанию + уведомления |
| `Watcher.ps1` | Слежение за папкой каждые 20 секунд |
| `Versions.ps1` | Снимки изменений и предыдущие версии |
| `CleanLogs.ps1` | Очистка старых логов и версий |
| `Restore.ps1` | Консольное восстановление |
| `InstallerGUI.ps1` | Графический установщик |
| `Update.ps1` | Проверка и установка обновлений с GitHub |
| `app_icon_v2.ico` | Иконка приложения |

## ⚙️ Планировщик заданий

| Задача | Что делает |
|---|---|
| `BackuperHourly` | Копирует файлы каждые 2 часа и при входе |
| `BackuperWatcher` | Следит за папкой, подхватывает изменения сразу |
| `BackuperLogCleanup` | Каждое воскресенье чистит старые логи и версии |
