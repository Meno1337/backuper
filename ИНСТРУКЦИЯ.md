# Backuper — инструкция

## Что делает (полностью автоматически)
- **Каждые 2 часа** и **при каждом входе в Windows** задача `BackuperHourly`
  копирует файлы из `\\Lpu6011-app010\transfer\карпов` в `C:\Users\karpovD\Desktop\backuper\Files`.
- **Слежение за папкой** (`BackuperWatcher`) проверяет сервер каждые **20 секунд**
  и мгновенно подхватывает новые/изменённые файлы — ждать 2 часа не нужно.
- **Всплывающее уведомление** в правом нижнем углу после каждого копирования:
  сколько файлов скопировано, или что сервер недоступен.
- **Файлы никогда не удаляются** из копии, даже если исчезли с сервера.
  Вместо этого пишется отчёт `Logs\missing_*.txt`.

## Логи и очистка (без засорения папки)
- По умолчанию логи хранятся **7 дней**.
- Каждую **неделю, в воскресенье в 23:00**, задача `BackuperLogCleanup` удаляет
  лог-файлы старше 7 дней. Дополнительно бэкап чистит старые логи при каждом запуске.
- Срок хранения меняется в панели: вкладка **Настройки** → поле **Keep logs (days)** →
  кнопка **Apply schedule**.
- Кнопка **Clean now** на вкладке Settings — очистить старые логи прямо сейчас.
- Текущий лог watcher'а не удаляется (он используется), остальные старые файлы — удаляются.

## Проверка, что всё работает
Откройте **Планировщик заданий** → «Библиотека планировщика заданий»:
- `BackuperHourly` — «Готово», следующий запуск через 2 часа;
- `BackuperWatcher` — «Выполняется» (постоянно работает в фоне);
- `BackuperLogCleanup` — «Готово», следующий запуск в воскресенье 23:00.

Если `BackuperWatcher` не запустился — панель → Settings → **Apply schedule**.

## Панель управления
Двойной клик по ярлыку **`Backuper`** на рабочем столе или по **`Открыть панель управления.cmd`**.
Оба запускают **`Backuper.exe`** — маленький лаунчер с собственной иконкой, который уже
запускает саму панель. Благодаря ему в панели задач и в трее отображается **наша иконка**
(`app_icon.ico`), а не иконка PowerShell. При сворачивании процесс остаётся в трее.

**Верхняя панель окна** — собственная, в стиле приложения: кнопки «−» (свернуть в трей),
«□» (развернуть/восстановить), «✕» (полный выход). Перетаскивание окна — за верхнюю панель.

**Сворачивание:** кнопка «−» убирает окно **в системный трей** (не на панель задач).
Одного щелчка по иконке в трее достаточно, чтобы окно вернулась (двойной клик тоже работает).
Правый клик по иконке открывает меню: «Открыть панель», «Копировать сейчас», «Выход».
Кнопка «✕» в окне закрывает программу полностью.

**Ползунки прокрутки** стилизованы: тонкие, тёмные, с зелёным ползунком при наведении.
Интерфейс полностью на русском. Списки вкладок **Восстановление** и **Версии**
обновляются автоматически каждые **5 секунд**, пока вкладка открыта
(раскрытые снимки и выбранный файл при этом сохраняются).

| Вкладка | Что можно |
|---|---|
| **Обзор** | «Copy now» (ручной запуск), статистика, список файлов, живой лог |
| **Восстановление** | Файлы, которых нет на сервере → выбрать → «Restore selected file» (подтверждение) |
| **Версии** | Раскрывающийся список снимков: `+ файл время` (добавлен/изменён), `- файл время` (удалён с сервера). Выберите строку → «To backup copy» или «To server». Также «Open folder», «Clean old», «Delete snapshot» |
| **Настройки** | Пути (кнопки «Выбрать...» открывают **современный диалог Проводника** — можно вставлять сетевой путь в адресную строку), интервал (2 ч), срок хранения логов (7 дней), папка версий и срок их хранения (30 дней), «Сохранить настройки», «Применить расписание», «Очистить сейчас» |

## Как вернуть исчезнувший файл
1. Панель → вкладка **Восстановление**.
2. Выбрать файл → **Restore selected file** → **Yes**.
3. Файл вернётся на сервер по исходному пути.
   Или консолью: `Восстановить файл.cmd` (пошагово, с подтверждением).

## Логи
Папка `Logs\`:
- `backup_*.log` — результаты копирования по расписанию;
- `watcher_*.log` — работа слежения за папкой;
- `missing_*.txt` — файлы, которые есть в копии, но пропали с сервера.

## Установка на другой ПК
1. Скачайте **только `BackuperInstaller.exe`** из
   [релиза](https://github.com/Meno1337/backuper/releases/latest) — архив не нужен.
   (Для локальной установки можно также скопировать всю папку `backuper`.)
2. Запустите **`BackuperInstaller.exe`** — он сам скачает файлы программы с GitHub,
   запросит права администратора и откроет **полноценный графический мастер установки**.
3. В окне мастера:
   - кнопкой «Выбрать папку» укажите **папку источника** на сервере;
   - укажите **папку установки** (по умолчанию `C:\Program Files (x86)\Backuper`);
   - отметьте, нужен ли **ярлык на рабочем столе**;
   - при желании нажмите «Проверить версию на GitHub» или «Скачать последнюю версию» —
     установщик обращается к репозиторию и может установить свежую сборку прямо оттуда.
4. Нажмите **«УСТАНОВИТЬ»** — мастер скопирует программу, создаст `settings.json`,
   зарегистрирует три задачи планировщика и запустит слежение. Ход установки виден в логе окна.

## Удаление программы
Скачайте **`BackuperUninstaller.exe`** из релиза. Мастер с ползунком прогресса и логом:
- удаляет задачи планировщика, ярлык и файлы программы;
- по умолчанию сохраняет `Files`, `Logs`, `Versions` и `settings.json` (можно снять галочку).

## Обновления с GitHub
- Репозиторий: **https://github.com/Meno1337/backuper** (адрес уже прописан в `version.json`).
- Для обновлений создайте в репозитории **Release** с ZIP-архивом файлов программы
  и тегом вида `v1.1.0` — кнопка «Проверить обновления» увидит новую версию.
- В панели: **Настройки → «Проверить обновления»** — покажет, есть ли новая версия.
- Полная установка обновления: `powershell -ExecutionPolicy Bypass -File Update.ps1`
  (без `-Check`). Пользовательские данные — `settings.json`, `Files`, `Logs`,
  `Versions` и ваша иконка — при обновлении сохраняются.

## История версий
- Перед каждым обновлением файла его **предыдущая версия** сохраняется в `Versions\ДД_ВРЕМЯ\`.
- Вкладка **Версии** показывает снимки в раскрывающемся дереве:
  - `+ 09:37:04  файл` — файл добавлен или изменён;
  - `- 09:37:34  файл` — файл исчез с сервера (копия сохранена).
- Выберите строку и нажмите **To backup copy** (вернуть версию в копию) или **To server**
  (вернуть версию на сервер, с подтверждением).
- Версии старше 30 дней удаляются по воскресеньям вместе со старыми логами,
  либо вручную кнопкой **Clean old**.

## Важное
- Копия лежит в подпапке `Files`. Не удаляйте её вручную.
- Если сервер недоступен — задача пришлёт уведомление с ошибкой; уже скопированные
  файлы останутся в безопасности.
- Watcher перезапускается автоматически при сбое и при каждом входе в Windows.

## Файлы
- `BackuperGUI.ps1` — графическая панель
- `Backup.ps1` — копирование по расписанию (с уведомлением)
- `BackupCore.ps1` — движок для панели (JSON)
- `Watcher.ps1` — слежение за папкой каждые 20 секунд
- `Versions.ps1` — модуль снимков (предыдущие версии + список изменений)
- `CleanLogs.ps1` — удаление старых логов и версий
- `Restore.ps1` — консольное восстановление
- `settings.json` — настройки путей (создаётся после сохранения в панели)
